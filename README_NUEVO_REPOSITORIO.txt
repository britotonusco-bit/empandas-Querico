EMPANADAS QUE RICO - REPOSITORIO NUEVO
======================================

Esta carpeta es la versión limpia preparada para subir a un repositorio NUEVO de GitHub.

ARCHIVOS PRINCIPALES
- index.html + script.js + estilos.css: página pública y pedidos.
- panel.html + panel.js + panel.css: panel administrativo.
- config.js: conexión con Supabase.
- SUPABASE_SINCRONIZACION_MAESTRA.sql: SQL maestro del catálogo y Realtime.

IMPORTANTE
1. No ejecutar sincronizar_menu_actual.sql: está marcado como OBSOLETO.
2. No ejecutar SQL adicional hasta terminar la prueba del repositorio.
3. Subir TODOS los archivos de esta carpeta al repositorio nuevo, manteniendo la raíz.
4. Activar GitHub Pages desde la rama principal (main) y carpeta raíz (/).

La conexión de Supabase ya está configurada en config.js según la versión base recibida.
